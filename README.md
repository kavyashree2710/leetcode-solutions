## 📝 Pattern Notes

<details>
<summary><strong>Two Pointers</strong></summary>

**Trigger signs:**
- Sorted arrays with pair or target-sum problems.
- Palindrome checks.
- Comparing elements from opposite ends.
- Removing duplicates in-place.

**Converging pointers:** Start at opposite ends and move inward.

```python
left, right = 0, len(nums) - 1

while left < right:
    if condition:
        left += 1
    else:
        right -= 1
```

**Read/write pointers:** Scan the array and write valid elements into their next available positions.

**Key insights:**
- Two Sum II: Move pointers based on whether the sum is smaller or larger than the target.
- Container With Most Water: Move the pointer at the shorter height.
- 3Sum: Sort, fix one number, use two pointers, and skip duplicates.
- Remove Duplicates: Track the position for the next unique value.
- Trapping Rain Water: Track `max_left` and `max_right`, processing the side with the smaller current height.

</details>

<details>
<summary><strong>Binary Search</strong></summary>

**Trigger signs:**
- Sorted or rotated arrays.
- Finding a value or boundary.
- Searching for the minimum or maximum feasible answer.

**Standard template:**

```python
left, right = 0, len(nums) - 1

while left <= right:
    mid = left + (right - left) // 2

    if nums[mid] == target:
        return mid
    elif nums[mid] < target:
        left = mid + 1
    else:
        right = mid - 1

return -1
```

**Key insights:**
- Rotated array: Identify the sorted half and check whether the target lies inside it.
- First and last position: Use two separate binary searches.
- Koko Eating Bananas: Binary-search the speed and check whether the total hours are `<= h`.
- Boundary conditions: Choose the loop condition based on the interval and termination logic.

</details>

## 🐞 Mistakes Log

<details>
<summary><strong>Open the log</strong></summary>

| Problem | Mistake | Lesson |
|---|---|---|
| Two Sum II | Missing `return`, mixed loop types, forgot 1-based indexing | Return immediately on a match and check output requirements |
| Valid Palindrome | Used `if` instead of `while` to skip characters | Use `while` when multiple characters may need skipping |
| 3Sum | Incorrect starting index and duplicate checks | Trace pointer movements and check neighboring values |
| Search in Rotated Array | Incorrect inclusive boundary | Identify the sorted half and apply the correct boundary condition |
| First/Last Position | Expanded outward from a match | Use two boundary binary searches |
| Koko Eating Bananas | Checked `== h` and returned hours instead of speed | Use `<= h` and return the minimum valid speed |
| Trapping Rain Water | Recalculated maxima repeatedly and compared indices instead of heights | Reuse running maxima and compare actual height values |

**Recurring theme:** Boundary conditions, off-by-one errors, and choosing the correct comparison operator.

**Improvement strategy:** Dry-run an example by hand before submitting.

</details>
